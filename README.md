# PhoneFileOrganizer · 文件管理

Android 文件管理工具公开下载页面。**本仓库仅用于分发安装包和版本说明，不包含应用源码。**

## 下载与安装
1. 进入 [Releases](https://github.com/xxxxfhhf/PhoneFileOrganizer-Releases/releases)。
2. 选择最新的正式版本或测试版本，展开 **Assets** 下载 `.apk` 文件。
3. 在 Android 手机上打开 APK，按系统提示确认安装；只从本仓库的 Release 下载。
4. 更新时优先直接覆盖安装，保留原应用数据。**若签名不同或版本降级，Android 可能拒绝覆盖安装；请勿为了升级直接卸载旧版。**

**当前状态：尚未上传经过编译和安装验证的公开 APK。仓库公开不等于已经发布安装包。**

## 功能
- 存储空间统计与应用占用分析
- 图片、视频、文档浏览与分类
- 用户授权共享目录的文件扫描
- 可访问文件的应用归属推测和有限的加密特征检测
- GitHub Release 版本检查（须使用公开可访问的发布源）

## 隐私与权限
本应用需要在 Android 授权范围内读取媒体及文件元数据。系统受保护的应用私有数据、聊天数据库及 Android 限制目录无法保证访问。文件归属推测和加密识别存在误判可能。发布前将补充正式隐私政策和权限清单。
